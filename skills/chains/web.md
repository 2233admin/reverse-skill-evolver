# chains-web 决策骨架（场景→判据→转向）

> 形式借鉴 ARTEX `agent/chainskel/`（AGPL-3.0）的决策骨架结构；**本文内容全部蒸馏自本包
> `skills/field-journal/` 自有种子，未复制 ARTEX 任何文本。** 每行末尾标注来源条目。

## 一、探测与 OOB

- 场景:探测目标是否存在带外触发型漏洞|判据:必须用 OOB 平台看有无回连，**本地无异常不等于不存在**|转向:多字段批量发 payload（User-Agent/Referer/X-Forwarded-For/登录名/搜索框）看 OOB 记录〔seed-012〕
- 场景:OOB 完全无回连|判据:目标在内网无外网出口|转向:改 DNS-only 通道；仍不通则走二阶反射（先打能出网的二级系统）〔seed-012〕
- 场景:有 DNS 回连但后续通道不通|判据:出网策略只放 DNS，或运行时版本禁用了远程类加载|转向:改用**本地 gadget chain**（不依赖远程类加载）；或直接用 DNS 做数据外带〔seed-012〕
- 场景:payload 被 WAF 拦|判据:命中现成规则|转向:用嵌套/大小写/env 回退等变形绕过；命令含特殊字符则 base64 包一层〔seed-012〕

## 二、认证与越权

- 场景:验证未授权访问|判据:去掉认证头后是否仍返回数据——**返回 200 + 数据才算未授权**|转向:先记录带凭据的正常响应作对照，再去掉凭据比对差异〔seed-003〕
- 场景:验证水平越权（IDOR）|判据:用 A 的凭据访问 B 的资源 ID，返回 B 的数据即确认|转向:**必须用自己的两个账号互测**，不碰他人数据；从响应中找 user_id 等差异字段佐证〔seed-003〕
- 场景:不知 API 结构|判据:Swagger/OpenAPI 文档暴露是最快入口|转向:试多个常见路径；拿到文档后按接口清单逐项测认证〔seed-003〕
- 场景:枚举被限流|判据:高频请求触发防护|转向:降速 + 正常 UA；限流是防护特征，不是"无此路径"的证据〔seed-003〕

## 三、SSRF 与云侧

- 场景:确认 SSRF 可利用深度|判据:能否访问内网地址是分界线|转向:先探内网端口，再试云元数据地址；不同云厂商路径不同需分别尝试〔seed-006〕
- 场景:元数据地址被黑名单拦|判据:按 IP 字面匹配|转向:换等价表示（IPv6 映射形式等）绕过字面匹配〔seed-006〕
- 场景:元数据要求 token 才返回|判据:IMDSv2 类防护需两步（先取 token 再带 token 请求）|转向:确认 SSRF 是否支持自定义 Method 与 Header；不支持则换路径〔seed-006〕
- 场景:拿到临时凭据|判据:STS token 有效期短（约 1 小时）|转向:写脚本自动刷新；用凭据先枚举权限范围再动数据〔seed-006〕

## 四、XML 实体注入（XXE）

- 场景:寻找 XXE 注入点|判据:任何接受 XML 的位置——请求体含 xml/soap、文档上传（docx/xlsx/pptx/SVG 本质是 zip+xml）|转向:按是否有回显分四路：有回显直接读文件；仅报错回显走 error-based；全无回显走 OOB 两层 DTD；DNS 通 HTTP 不通走 DNS 外带〔seed-017〕
- 场景:直接文件实体引用报错|判据:解析器禁用了通用实体|转向:改用参数实体嵌套；文件含特殊字符则加编码过滤器包裹〔seed-017〕
- 场景:OOB 有回连但取不到内容|判据:DTD 嵌套层数或拼接位置错误|转向:严格对照两层 DTD 模板（外层声明 + 内层发送实体），不要凭记忆拼〔seed-017〕
- 场景:文件只读到一部分|判据:解析器有实体长度上限|转向:分段读取并带偏移量拼接〔seed-017〕
- 场景:内网探测全部拒绝连接|判据:应用所在网段未开放内部服务|转向:改试本机回环、内部服务名（容器编排环境用服务名而非 IP）〔seed-017〕
- 场景:Java 应用打不通|判据:新版默认禁用外部实体协议|转向:试其他可用协议；或确认该接口是否用了旧版解析器〔seed-017〕
- 场景:XXE 已确认，如何扩大影响|判据:文件读取与 SSRF 是同一原语的两个方向|转向:读应用配置（凭据/私钥）；或转 SSRF 打云元数据（见 `web.md` 第三节）〔seed-017〕

## 五、证据与交付

- 场景:报告被判定不可复现|判据:只有截图、无完整请求响应|转向:附可复现的命令与完整请求/响应；证据先脱敏〔seed-003〕
- 场景:声称漏洞确认|判据:必须区分"机理成立"与"实际可利用"|转向:至少给出一条端到端可复现路径，否则降级为 candidate〔seed-012〕〔seed-003〕
